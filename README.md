# YouTube FloatPlayer

Chrome-расширение: кнопка в панели плеера YouTube выносит видео в окно
**поверх всех окон** (Document Picture-in-Picture) с полными контролами.

## Чем отличается от аналогов

- Настоящее always-on-top окно (Document PiP API, Chrome 116+), а не обычный popup.
- Переносится **весь плеер YouTube**: работают родные таймлайн, главы,
  субтитры, качество, next/prev — без второго потока и прерывания.
- Мини-окно можно **таскать за любое место** (app-region: drag), не только за заголовок;
  контролы и меню YouTube при этом кликабельны.
- Окно открывается **без чёрных полос**: высота подгоняется под пропорции видео.
- Дополнительная панель сверху мини-окна (низ занят родным таймлайном YouTube):
  - **A-B повтор** фрагмента (клик 1 — точка A, клик 2 — точка B, клик 3 — сброс);
  - **скорость** 0.25x–3x кнопками −/+ (клик по «1x» — сброс);
  - **громкость 0–300%** (Web Audio: тише нуля YouTube и громче максимума);
  - возврат видео на страницу.
- Хоткеи внутри мини-окна: пробел/K — пауза, стрелки ←/→ — ±5 сек, M — mute.
- Горячие клавиши (работают при фокусе в любом окне Chrome):
  `Alt+P` — открыть/закрыть, `Alt+K` — пауза, `Alt+J`/`Alt+L` — ±5 сек.
  Переназначение: `chrome://extensions/shortcuts`.
- Авто-PiP при уходе со вкладки (опция, выключена по умолчанию, Chrome 120+).
- Минимум разрешений: `storage` + youtube.com. Без сборщика, без remote code.

## Установка (разработка)

1. Открыть `chrome://extensions`.
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку `extension/`.
4. Открыть любое видео на YouTube — кнопка появится слева от шестерёнки.

## Ограничения (честно)

- Chrome 116+ обязателен (на старых — фолбэк на нативный PiP без наших контролов).
- Прозрачность окна и «клик сквозь окно» невозможны в Chrome API в принципе.
- Одно PiP-окно на браузер (ограничение Chrome).
- Пока окно открыто, плеер на странице заменён заглушкой «Вернуть сюда» — это норма.

## Разработка

```
extension/
├── manifest.json           MV3
├── content/                контент-скрипты (порядок загрузки важен)
│   ├── constants.js        селекторы YouTube + дефолты (единая точка правок)
│   ├── utils.js            чистая логика (покрыта тестами)
│   ├── settings.js         chrome.storage.sync + кэш
│   ├── player-api.js       обёртка над DOM плеера
│   ├── audio-boost.js      Web Audio gain
│   ├── pip-controls.js     панель функций в PiP-окне
│   ├── pip-controller.js   перенос плеера в Document PiP и обратно
│   └── inject-button.js    кнопка, SPA-навигация, хоткеи, авто-PiP
├── pip/pip.css             стили PiP-окна
├── background/             service worker (chrome.commands)
├── options/                страница настроек
└── _locales/               ru/en
```

Тесты: `npm install && npm test` (vitest, чистые функции utils).
