# План: прозрачность панели чата/комментариев + мелкая полировка

Контекст: расширение Chrome MV3 «FloatPlayer». Панель чата и комментариев —
одна и та же выдвижная колонка `.ytfp-chat-panel` в PiP-окне; её задник
захардкожен как `rgba(15, 15, 15, 0.5)` в `extension/pip/pip.css:1109`.
Прозрачность самой страницы чата уже обеспечена (pip-chat.js гасит фон
внутри iframe). Нужна одна настройка-процент, управляющая альфой задника.

## Часть A. Настройка «Прозрачность панели чата», %

1. `extension/content/constants.js`: в `YTFP.DEFAULT_SETTINGS` добавить
   `chatPanelOpacity: 50` (проценты НЕпрозрачности фона, 0–100; 50 = как
   сейчас).
   → verify: `npx vitest run` зелёный.

2. `extension/pip/pip.css`: у `.ytfp-chat-panel` заменить фон на
   `background: rgba(15, 15, 15, var(--ytfp-chat-bg-alpha, 0.5));`
   → verify: без настройки вид не меняется (fallback 0.5).

3. `extension/content/pip-chat.js`: в `build()` выставлять переменную на
   корне документа окна:
   `pipDocument.documentElement.style.setProperty("--ytfp-chat-bg-alpha", pct/100)`
   из `YTFP.settings.get().chatPanelOpacity`; подписаться на
   `YTFP.settings.onChange` — меняется живьём, без переоткрытия окна.
   Нормализация: не число / вне 0–100 → 50.
   → verify: юнит-тест на функцию нормализации.

4. `extension/options/options.html` + `options.js`: слайдер
   `<input type="range" min="0" max="100" step="5">` рядом с настройками
   окна + подпись со значением в % (по образцу существующих слайдеров
   speedStep / volumeBoost). В `DEFAULT_SETTINGS` options.js добавить
   `chatPanelOpacity: 50`.
   → verify: открыть страницу настроек, двигать слайдер, значение
   сохраняется и применяется в открытом PiP-окне.

5. Локали: ключи `optChatOpacityLabel` (+ hint, если нужен) во все
   14 файлов `extension/_locales/*/messages.json`.
   → verify: скрипт сравнения множеств ключей с en (как в релиз-плане).

6. Тест: сверка, что `DEFAULT_SETTINGS` options.js — подмножество
   `YTFP.DEFAULT_SETTINGS` без расхождений по значениям (закрывает и
   пункт полировки B3 ниже).
   → verify: `npx vitest run`.

Не делаем (YAGNI): отдельные ползунки для чата и комментариев (панель
одна), прозрачность текста (нечитаемо), ползунок внутри самого PiP-окна
(добавим позже, если попросишь — место в капсуле ограничено).
