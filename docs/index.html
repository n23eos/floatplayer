What it does

Everything lives in one hover panel, one button row and one progress strip.

Always on top, for real

Document Picture-in-Picture gives a genuine OS-level window — not a popup that falls behind your editor.

The same video stream

The actual YouTube player is moved, so your account, history, quality and captions carry over without a restart.

Video only

Shopping overlays, cards, endscreens and descriptions are hidden by a whitelist — the window shows the video and nothing else.

A-B loop

Mark two points and repeat a fragment — for language practice, music, tutorials or technique review.

Volume 0–300%

Web Audio gain goes quieter than YouTube's zero and far louder than its maximum for quiet recordings.

Night mode

Two strengths pull the blue out of the picture for late viewing, without touching the captions or the panel.

Sleep timer

Presets or your own value up to 12 hours. While it counts down the interface hides itself completely.

Comments and live chat

A side column brings YouTube's comments — scrolling endlessly — or a stream's live chat next to the video.

Sponsor segments

Community SponsorBlock data marks in-video sponsor reads in green; skip them yourself or let it skip automatically.

Live streams

A LIVE badge shows how far behind you are and returns you to the edge; seeking works across the DVR buffer.

Shorts mode

A button above Like pops a short into a vertical window; the next one starts automatically when it ends.

Snaps to the video

The window opens at the video's aspect ratio and snaps back after resizing — no black margins, no stray UI.

See it

Regular videos, Shorts and the options page.

Requirements and honest limits

  • Chrome 116 or newer; older versions fall back to native Picture-in-Picture.
  • Chrome always draws a small strip with the site address on top of any Document PiP window — an anti-phishing rule no extension can remove. It hides itself when the cursor is away, and "clean video" mode has no strip at all.
  • Window position cannot be set programmatically; only its size is remembered.
  • One PiP window per browser.
  • YouTube ads are neither blocked nor skipped, and seeking is unavailable while one plays.
  • No analytics, no accounts, no data collection. The only network call is an optional SponsorBlock lookup by video ID.
