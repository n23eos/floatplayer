FloatPlayer

Privacy Policy

Last updated: 28 July 2026

The developer of FloatPlayer collects no data. The extension has no analytics, no trackers, no accounts and no servers of its own — nothing reaches us, and nothing is ever sold or shared.

One optional feature does send data to a third party, and it is disclosed in the Chrome Web Store listing under web history: see what is transmitted below.

Stored locally

  • Your settings (window style, speed step, volume ceiling, sleep timer, Shorts auto-advance, panel behaviour) live in Chrome's storage.sync, inside your browser and your Google profile sync. We have no access to them.
  • The last window width is stored the same way, separately for landscape videos and vertical Shorts.

Network requests

  • When the sponsor segments (SponsorBlock) feature is enabled — it is on by default and can be switched off on the options page — the extension sends the ID of the YouTube video you are watching to the community API sponsor.ajay.app to fetch sponsor-segment timestamps. No cookies, account data or personal identifiers accompany that request. See SponsorBlock's own privacy policy.
  • Thumbnails in the recommendations column load from YouTube's standard image host (i.ytimg.com), exactly as YouTube itself loads them.

What is transmitted, and what we do with it

When the sponsor-segment feature is on, the ID of the video you are watching goes to sponsor.ajay.app — nothing else. That single fact is the "web history" category declared in our Chrome Web Store listing. Turning the feature off in the options stops those requests entirely.

  • The data is not sold or transferred to third parties, except for the lookup described above, which is the feature itself.
  • It is not used for any purpose unrelated to the extension's single function: controlling YouTube playback in a floating window.
  • It is not used to determine creditworthiness or for lending purposes.

Clipboard

The "copy video link" button writes the current video URL to your clipboard only when you click it. The clipboard is never read.

Permissions and why they exist

  • storage — saving the settings described above.
  • clipboardWrite — the copy-link button.
  • Access to youtube.com — adding the buttons to the player, moving the player into the floating window and controlling playback.
  • Access to sponsor.ajay.app — fetching sponsor-segment timestamps, only while that feature is enabled.

Русская версия

Разработчик FloatPlayer не собирает данные. Аналитики, трекеров, аккаунтов и собственных серверов нет — до нас ничего не доходит, данные не продаются и не передаются.

Одна необязательная функция отправляет данные стороннему сервису — это и есть категория «история веб-поиска», заявленная в листинге Chrome Web Store: при включённых интеграциях на sponsor.ajay.app уходит только ID просматриваемого видео. Данные не продаются, не используются для целей вне основной функции расширения и не применяются для оценки кредитоспособности. Отключение функции в настройках полностью прекращает эти запросы.

Локально хранятся только ваши настройки и последняя ширина окна — в storage.sync Chrome, внутри вашего браузера.

Сетевые запросы: при включённой функции «интеграции на таймлайне» на sponsor.ajay.app отправляется только ID просматриваемого видео (функция отключается в настройках); обложки рекомендаций грузятся со стандартного хоста картинок YouTube.

Буфер обмена: кнопка «скопировать ссылку» пишет адрес видео в буфер только по вашему клику; чтение не выполняется.

Разрешения: storage — настройки; clipboardWrite — копирование ссылки; доступ к youtube.com — кнопки и управление плеером; доступ к sponsor.ajay.app — границы спонсорских вставок.
