Privacy Policy

Last updated: 31 July 2026

The developer of FloatPlayer collects no data. The extension has no analytics, no trackers, no accounts and no servers of its own — nothing reaches us, and nothing is ever sold or shared.

One optional feature sends data to a third party, and it is disclosed in the Chrome Web Store listing under web history: see what is transmitted below. Everything else the extension requests over the network goes to YouTube itself, from the YouTube tab you already have open.

Stored locally

  • Your settings (window style, speed step, volume ceiling, sleep timer, night mode, SponsorBlock options, Shorts auto-advance, panel behaviour) live in Chrome's storage.sync, inside your browser and your Google profile sync. We have no access to them.
  • The last mini-window width lives in storage.local, separately for landscape videos and vertical Shorts, next to a one-time flag remembering that the first-run hint has been shown.

Network requests

  • When the sponsor segments (SponsorBlock) feature is enabled — it is on by default and can be switched off on the options page — the extension sends the ID of the YouTube video you are watching to the community API sponsor.ajay.app to fetch sponsor-segment timestamps. No cookies, account data or personal identifiers accompany that request. See SponsorBlock's own privacy policy.
  • Opening the comments column asks YouTube for the comments exactly as the page itself does: a request to www.youtube.com/youtubei/v1/next from the YouTube tab, carrying the YouTube session you are already signed in to and your interface language. It goes to YouTube and nowhere else — we receive nothing, and it only happens when you open that column.
  • Opening the live chat of a stream loads YouTube's own www.youtube.com/live_chat page inside the window, again under your existing session.
  • Thumbnails in the recommendations column load from YouTube's standard image host (i.ytimg.com), exactly as YouTube itself loads them.

Links to Google Forms

The options page has a Report a bug link, and Chrome opens a short feedback form once you uninstall the extension. Both are ordinary Google Forms pages. Nothing is pre-filled, attached or submitted on your behalf — opening one is a normal website visit, covered by Google's own privacy policy, and you can close the tab without answering anything.

What is transmitted, and what we do with it

When the sponsor-segment feature is on, the ID of the video you are watching goes to sponsor.ajay.app — nothing else leaves for a third party. That single fact is the "web history" category declared in our Chrome Web Store listing. Turning the feature off in the options stops those requests entirely.

  • The data is not sold or transferred to third parties, except for the lookup described above, which is the feature itself.
  • It is not used for any purpose unrelated to the extension's single function: controlling YouTube playback in a floating window.
  • It is not used to determine creditworthiness or for lending purposes.

Permissions and why they exist

  • storage — saving the settings described above.
  • Access to youtube.com — adding the buttons to the player, moving the player into the floating window, controlling playback, and loading comments and live chat when you open them.
  • Access to sponsor.ajay.app — fetching sponsor-segment timestamps, only while that feature is enabled.

Русская версия

Разработчик FloatPlayer не собирает данные. Аналитики, трекеров, аккаунтов и собственных серверов нет — до нас ничего не доходит, данные не продаются и не передаются.

Одна необязательная функция отправляет данные стороннему сервису — это и есть категория «история веб-поиска», заявленная в листинге Chrome Web Store: при включённых спонсорских вставках на sponsor.ajay.app уходит только ID просматриваемого видео. Данные не продаются, не используются для целей вне основной функции расширения и не применяются для оценки кредитоспособности. Отключение функции в настройках полностью прекращает эти запросы.

Локально хранятся ваши настройки (в storage.sync Chrome) и последняя ширина мини-окна вместе с отметкой о показанной подсказке (в storage.local) — всё внутри вашего браузера.

Сетевые запросы: при включённой функции «спонсорские вставки» на sponsor.ajay.app отправляется только ID просматриваемого видео (функция отключается в настройках). Когда вы открываете комментарии, расширение запрашивает их у YouTube так же, как это делает сама страница — запросом на www.youtube.com/youtubei/v1/next с той сессией YouTube, под которой вы уже вошли; чат эфира загружается страницей www.youtube.com/live_chat. Всё это уходит только к YouTube. Обложки рекомендаций грузятся со стандартного хоста картинок YouTube.

Ссылки на Google Формы: в настройках есть ссылка «Сообщить об ошибке», а после удаления расширения Chrome открывает форму обратной связи. Ничего не подставляется и не отправляется за вас — это обычный переход на страницу Google Форм, вкладку можно просто закрыть.

Разрешения: storage — настройки; доступ к youtube.com — кнопки, управление плеером, комментарии и чат эфира; доступ к sponsor.ajay.app — границы спонсорских вставок.
