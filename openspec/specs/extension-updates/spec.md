# extension-updates

## Purpose

Позволять пользователю проверять доступность обновления FloatPlayer и применять подготовленную Chrome версию из небольшого popup расширения.

## Requirements

### Requirement: Проверка обновления
Popup SHALL показывать текущую версию и действие проверки, различать доступное обновление, отсутствие, ограничение частоты и ошибку. Автоматическое уведомление Chrome SHALL отражаться при открытии popup без частых принудительных проверок.

#### Scenario: Проверка пользователем
- **WHEN** пользователь нажимает проверку
- **THEN** кнопка временно блокируется, затем показывается фактический результат Chrome с возможностью повтора

#### Scenario: Локальная установка
- **WHEN** расширение установлено распакованным
- **THEN** popup объясняет ручное обновление файлов и перезагрузку расширения вместо обещания загрузки из магазина

### Requirement: Установка подготовленной версии
Popup SHALL предлагать обновление только для подтвержденной новой версии и применять его только по нажатию пользователя. Перед применением пользователь SHALL видеть указание закрыть плавающий плеер и обновить вкладки после установки. Если обнаружено открытое окно FloatPlayer, установка SHALL быть отложена до его закрытия.

#### Scenario: Обновление готово
- **WHEN** Chrome сообщает о новой версии, пользователь закрыл плавающие окна и нажал установку
- **THEN** расширение запрашивает применение подготовленного обновления через штатный механизм Chrome

#### Scenario: Активное окно или устаревшая запись
- **WHEN** окно FloatPlayer открыто либо сохраненная доступная версия не новее установленной
- **THEN** перезапуск не выполняется; показывается требуемое действие либо обычная проверка обновлений

#### Scenario: Вкладка не отвечает
- **WHEN** состояние окна невозможно подтвердить, включая отсутствие content script после перезагрузки расширения
- **THEN** установка откладывается с предложением обновить или закрыть такую вкладку и повторить попытку
