# pip-chapters Specification

## Purpose
Показывать названия глав текущего видео и обеспечивать переходы внутри полного PiP без ручного открытия панели YouTube.

## Requirements

### Requirement: Главы текущего видео
Полный PiP SHALL получать названия глав без необходимости вручную открывать панель YouTube, проверяя принадлежность текущему видео.
#### Scenario: Панель не открыта
- **WHEN** публичные данные текущего видео содержат главы
- **THEN** PiP показывает текущую главу и доступный список переходов
#### Scenario: Смена видео
- **WHEN** данные принадлежат предыдущему videoId
- **THEN** они не отображаются для нового видео

### Requirement: Переход по главам
Список SHALL позволять перейти к началу главы и сохранять состояние паузы.
#### Scenario: Выбор главы
- **WHEN** пользователь выбирает главу на паузе
- **THEN** время меняется на начало главы и пауза сохраняется
#### Scenario: Нет данных
- **WHEN** названия глав недоступны
- **THEN** интерфейс не выдумывает названия

#### Scenario: Реклама
- **WHEN** плеер показывает рекламу
- **THEN** подпись и список глав скрываются до возврата основного видео

### Requirement: Расположение строки главы
Строка главы SHALL располагаться компактным блоком справа ниже панели управления и выше таймлайна, не растягиваясь на всю ширину окна.
#### Scenario: Отображение глав
- **WHEN** названия глав доступны
- **THEN** панель оставляет место строке главы снизу без перекрытия кнопок или таймлайна
