## Context
Vanilla JS/MV3. Уже существуют два PiP API и частичное извлечение глав из DOM.
## Goals / Non-Goals
Исправить главы и обнаруживаемость режимов без переделки компоновки всех панелей. Не добавлять HTML в Native PiP и не скрывать системную рамку Chrome.
## Decisions
Использовать публичные JSON/DOM данные, проверку videoId и локальный ограниченный кеш. Источники без подтверждённой принадлежности отбрасывать. UI глав строится в pip-progress. Режим хранится существующим windowMode, подсказки EN/RU и fallback в других локалях. Компактность уважает существующую настройку.
## Risks / Trade-offs
YouTube меняет структуру данных: нужны фикстуры, отрицательные сценарии и явное отсутствие глав при нехватке данных. Стенд не доказывает живую интеграцию.
## Migration Plan
Без миграции хранилища; обновление файлов расширения. Откат локального изменения не затрагивает пользовательские данные.
