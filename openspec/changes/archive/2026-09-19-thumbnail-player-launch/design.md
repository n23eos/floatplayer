## Context

См. proposal.md. pip-controller переносит готовый #movie_player и восстанавливает его по placeholder. Сейчас открытие требует страницы watch/shorts. navigation.go использует MAIN bridge и подтверждает только адрес после yt-navigate-finish. Chrome 116+ требует пользовательский жест для requestWindow, поэтому ждать загрузку до открытия окна нельзя.

## Goals / Non-Goals

**Goals:** переиспользовать полный плеер и его восстановление, ограничить ожидание, не переносить hover-preview или старый ролик.

**Non-Goals:** iframe/embed-плеер, сохранение ленты во вкладке, новые разрешения или настройки.

## Decisions

- Новый thumbnail-launch модуль обслуживает только главную страницу и известные thumbnail-контейнеры обычных карточек. Кнопка является соседним элементом ссылки; события кнопки не всплывают в карточку. ID читается заново при клике.
- MutationObserver включен только на главной, группирует изменения; переход отключает наблюдение. Узкие селекторы, отсутствие постоянного опроса карточек. Реклама, Shorts и сомнительные ссылки пропускаются.
- pip.openVideo открывает окно синхронно до первого await, показывает загрузку и удерживает блокировку запуска. После navigation.go и waitForPlayer используется общий путь наполнения уже открытого окна. Стандартное open сохраняет поведение.
- MAIN bridge подтверждает актуальный video_id через getVideoData и готовность video. Коррелированные сообщения и ограниченный опрос существуют только во время запуска. Проверяются source, origin, target ID, URL; AbortSignal снимает слушатели и таймеры.
- Отказ/закрытие окна освобождает запуск, ошибка показывается на странице; повтор возможен. Полный режим используется разово без записи настроек. Новые строки EN/RU, для других языков английский fallback.
- Размер стартового окна соответствует стандартному горизонтальному размеру. После загрузки применяется существующая геометрия плеера.

## Risks / Trade-offs

- Изменение DOM/внутреннего роутера YouTube: пропуск неизвестных карточек и ограниченный отказ без переноса плеера.
- Переход может оставить watch-страницу при закрытии окна: отменяется ожидание, завершившаяся навигация не откатывается.
- Локальный стенд подтверждает UI и жизненный цикл, но реальная интеграция требует проверки установленного расширения на YouTube.
- Реклама внутри обычного ролика остается частью родного плеера и не пропускается.

## Migration Plan

Миграций данных нет. Добавить модуль в manifest и тестовый загрузчик, собрать ZIP. Откат состоит в удалении новой точки входа; настройки не менялись.
