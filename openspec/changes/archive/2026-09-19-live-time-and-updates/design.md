## Context

См. proposal.md. На живой странице подтверждены currentTime=5410.42, duration/seekable.end=7810.233, native progress max/now=5398, native badge livehead=true. Текущий расчет дает ложные -39:58. Popup и service worker пока не содержат обновлений.

## Goals / Non-Goals

**Goals:** корректировать источник времени, сохранить паузу/рекламу/обычные видео, использовать штатный Chrome update API без новых разрешений.
**Non-Goals:** публикация в магазине, внешняя загрузка пакетов, принудительное обновление активных YouTube-вкладок.

## Decisions

- Native livehead имеет приоритет при воспроизведении. Native progress aria границы используются только при числовой корректности и согласованности aria-valuenow с media.currentTime (допуск на обновление UI). При отсутствии достоверных данных live range неизвестен; raw seekable не служит доказательством края эфира.
- Возврат к эфиру через родную live badge; ручной fallback только по проверенному диапазону. Во время рекламы live UI скрыт. Данные читаются из корня того же video, включая перенесенный PiP.
- Service worker сохраняет onUpdateAvailable version локально, сравнивает с установленной и дает popup состояние. requestUpdateCheck только по нажатию. management.getSelf различает unpacked без permission management.
- Кнопка установки доступна для подтвержденной версии; перед runtime.reload проверяем все известные YouTube-вкладки на открытый PiP. Вместо автоматического закрытия попросим пользователя закрыть окно и повторить установку. Неопределенное состояние уже отвечающей вкладки обрабатывается как ошибка, не успех.
- Popup update UI изолирован от управления видео. При открытии читает сохраненное состояние, слушает storage для уведомлений. Проверка и установка сериализованы, ошибки возвращают возможность повтора. EN/RU и английский fallback; без новых зависимостей.

## Risks / Trade-offs

- Родная разметка может измениться: нейтральный статус и отключение недостоверной шкалы предпочтительнее ложного отставания.
- Chrome решает доступность и время обновления; неопубликованную локальную сборку кнопка не скачивает.
- После runtime.reload открытым вкладкам требуется обновление пользователем; popup объясняет это до установки.
- Локальный стенд подменяет Chrome update API; настоящая установка пакета в этой задаче не выполняется.

## Проверенные уточнения
- На паузе native max позади currentTime означает неизвестный диапазон; перемотка вперёд не откатывает позицию назад.
- Capture-фильтр PiP пропускает синтетический click только по родной live badge. Остальные клики по видео остаются заблокированы.
- Компактная подпись «Эфир ?» и отдельное место в строке исключают наложение на перемотку при 360x300.
- Отсутствие receiver не доказывает отсутствие старого PiP после reload. Установка откладывается до обновления/закрытия неотвечающей вкладки.
