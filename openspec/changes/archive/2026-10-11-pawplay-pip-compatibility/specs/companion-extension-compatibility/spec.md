## Purpose

Дать совместимым расширениям стабильный способ обнаружить Document PiP FloatPlayer, его таймлайн и жизненный цикл без зависимости от внутренних классов.

## ADDED Requirements

### Requirement: Версионированный контракт Document PiP
FloatPlayer SHALL помечать готовый Document PiP и его таймлайн стабильными версионированными DOM-атрибутами. Таймлайн SHALL публиковать текущий диапазон, положение и доступность через стандартные ARIA-атрибуты.

#### Scenario: Полное или компактное окно готово
- **WHEN** FloatPlayer закончил строить полное либо компактное Document PiP
- **THEN** корень PiP-документа содержит маркер Document PiP и версию контракта, а таймлайн доступен через стабильный атрибут и содержит `aria-valuemin`, `aria-valuemax`, `aria-valuenow` и `aria-disabled`

#### Scenario: Native video-only PiP
- **WHEN** пользователь открывает native video-only PiP
- **THEN** FloatPlayer не обещает DOM-контракт таймлайна, поскольку этот режим не предоставляет отдельный управляемый документ

#### Scenario: Замена paused video и реклама
- **WHEN** YouTube заменяет остановленный video, новый media становится готов либо player входит в рекламу без `timeupdate`
- **THEN** ARIA-состояние таймлайна обновляется по media lifecycle и классу player root без ложного доступного прогресса

### Requirement: События жизненного цикла интеграции
Исходный документ YouTube SHALL получать версионированное событие готовности только после создания доступного таймлайна Document PiP и событие закрытия при завершении этого окна.

#### Scenario: Совместимое расширение ожидает готовность
- **WHEN** FloatPlayer полностью собрал Document PiP
- **THEN** исходный документ получает событие готовности версии 1, после которого совместимое расширение может прочитать PiP-документ и найти таймлайн

#### Scenario: Окно закрыто
- **WHEN** Document PiP закрывается и FloatPlayer начинает возвращать плеер на страницу
- **THEN** исходный документ получает событие закрытия версии 1 ровно для завершенного жизненного цикла

### Requirement: Ссылка на PawPlay
Страница настроек FloatPlayer SHALL содержать в нижнем блоке прямую ссылку на карточку PawPlay в Chrome Web Store.

#### Scenario: Переход к PawPlay
- **WHEN** пользователь нажимает ссылку PawPlay внизу настроек
- **THEN** открывается карточка расширения с идентификатором `hiclbjaochideikofjcjldfioonefghn` в новой вкладке без доступа открытой страницы к объекту исходного окна
