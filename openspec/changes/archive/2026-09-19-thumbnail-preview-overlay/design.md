## Решение
Отдельная кнопка внутри media-container предпросмотра, вне ссылки, выше видео. Привязка только по media-container-link к проверенной карточке; повторная проверка ID при клике. Существующий MutationObserver отслеживает URL и замену DOM, ResizeObserver размер. Родитель скрывает кнопку вместе со слоем.

## Проверки
Регрессии смены ID, рекламы, удаления, навигации. Стенд воспроизводит отдельный слой поверх карточки. CUA проверяет видимость и запуск.
