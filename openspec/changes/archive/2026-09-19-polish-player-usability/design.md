## Context

См. proposal.md. Таймер сейчас переносит в закрепленную панель весь блок select/countdown/+10. История доступна только в отключенном shortsPanel. Таймлайн слушает начальный video; панель страницы измеряет геометрию каждые 500 мс. Используются существующие Vanilla JS, CSS, Vitest/jsdom и CUA-стенд.

## Goals / Non-Goals

**Goals:** исправить подтвержденные дефекты, сделать счетчик таймера компактным, сохранить привычные цвета и общую компоновку, обеспечить клавиатуру и понятные ошибки.

**Non-Goals:** возврат боковой панели Shorts, миграция истории, новые зависимости или разрешения, переработка механизма сна и публикация.

## Decisions

- Таймер имеет одну кнопку с иконкой часов и числом, фиксированную ширину цифр. Настройки раскрываются в отдельной компактной панели внутри viewport. Это сохраняет работоспособность при переносе узла между меню и закрепленной строкой; постоянно видимый select отклонен как причина перегрузки.
- История использует существующие localRecords и shortsRuntime.revisit; отдельный небольшой модуль включается перед pip-controls, без копии хранилища. Отключенная настройка shortsSide остается совместимой в схеме, но исчезает из формы.
- Меню получает группы и видимую подпись закрепления. Для свернутых составных инструментов, включая таймер, сохраняется единый интерфейс DOM-узла.
- Popup обрабатывает отказ команды и не закрывается. Options имеет явные loading/error/ready состояния и кнопку повторной загрузки; при ошибке форма недоступна.
- Таймлайн перепривязывает события при замене video, отсоединяет их при cleanup, предоставляет slider ARIA и ограниченную диапазоном клавиатурную перемотку. CSS дает 24px области попадания при тонкой визуальной полосе.
- Геометрия панели обновляется через существующие наблюдатели размеров и события. Отключенный SponsorBlock снимает listeners. Без обещаний ускорения CPU до измерения.
- Новые строки добавляются централизованно в EN/RU, остальные локали получают английский fallback. Данные и разрешения не меняются; новые обработчики всегда имеют cleanup.

## Risks / Trade-offs

- Вложенные раскрытия таймера/истории могут конфликтовать с закрытием общего меню -> проверки клика снаружи, Escape и переноса закрепленного элемента.
- YouTube заменяет video нестандартно -> регрессия замены элемента, проверка наблюдателя и очистки.
- Стенд подменяет YouTube API -> явное указание ограничения живой интеграции в STATUS и отчете.

## Migration Plan

Сохраненные настройки читаются как раньше. Обновляется сборка расширения, без удаления пользовательских данных. Откат возможен возвратом предыдущей версии кода; schema storage совместима.
