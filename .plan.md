# План: нижние органы управления — одна прозрачная капсула

Сейчас внизу мини-окна три независимых плавающих элемента: оценки слева,
ряд навигации по центру, кнопка чата/комментариев справа. Каждая кнопка
со своей тёмной подложкой.

Цель: одна капсула по центру низа, в стилистике верхней панели
(полупрозрачный фон + размытие), а внутри — [лайк дизлайк] [−30 назад
play вперёд +30] [комментарии]. Подложки у отдельных кнопок убираем,
остаётся подсветка при наведении.

## Шаги

1. pip-nav.js → возвращать ряд кнопок отдельно от корня.
   Центральный значок паузы и подсказка перемотки остаются поверх видео,
   в капсулу уходит только ряд.
   → verify: значок паузы по центру кадра, ряд внутри капсулы.

2. pip-chat.js → возвращать кнопку отдельно от выдвижной колонки.
   Колонка остаётся абсолютной у правого края, кнопка уходит в капсулу.
   → verify: колонка открывается, кнопка не уезжает вместе с ней.

3. pip-controller.js → собрать .ytfp-bottom и сложить в неё
   [оценки, ряд навигации, кнопка чата].

4. pip.css → капсула; у .ytfp-reactions / .ytfp-nav / .ytfp-chat-toggle
   снять абсолютное позиционирование и собственную видимость; у кнопок
   убрать подложку. Скрытие по таймеру сна — на капсулу.
   В узком окне (media-запрос) прятать кнопки ±30, иначе капсула не влезает.
   → verify: рендер в 480 и 320 px, капсула не шире окна.

5. Проверка на стенде (реальные скрипты в headless Chrome):
   окно открывается, все три группы внутри одного контейнера.
