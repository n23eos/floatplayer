# План: 7 новых фич для FloatPlayer (v1.8)

Одобрено пользователем («составь план и сделай»). Каждая фича — изолированный слой,
существующая логика не переписывается. Прежний план v1.0 выполнен и заархивирован git-историей.

## Обнаружено при чтении кода

- Хоткеи в PiP-окне уже есть: Space/K, ←/→ (5с), M, </>. Фича 1 = дополнить.
- Глобальные команды уже есть: Alt+P/K/J/L (работают при фокусе в Chrome).
  Фича 7 = команда с `"global": true` (работает вне Chrome).
- Web Audio цепочка в audio-boost.js: source → gain → destination. Фича 2 = вставить фильтры.
- i18n: везде `t(key, fallback)` с англ. фолбэком → новые строки только в en+ru,
  остальные 12 локалей получают английский (штатный фолбэк Chrome).
- «Прозрачность окна» из идей ОТБРОШЕНА: PiP-окно — непрозрачная поверхность ОС,
  CSS opacity не покажет окна позади (зафиксировано ещё в плане v1.0).

## Шаги

1. **Хоткеи** (pip-controls.js, constants.js)
   - ↑/↓ — громкость ±10% (через audioBoost, синхронизация со слайдером и подписью);
   - 0–9 — прыжок на N×10% длительности (не во время рекламы);
   - SEEK_STEP_SECONDS 5 → 10 (запрошено «±10с»; затронет и Alt+J/L — консистентно).
   - verify: юнит-тест digitSeekTime, ручная проверка клавиш.

2. **Аудио-пресеты** (audio-boost.js, pip-controls.js, constants, options, i18n)
   - Цепочка: source → lowshelf → peaking → compressor → gain → dest.
     Нейтральные параметры = «off» (прозрачно, компрессор ratio 1).
   - Пресеты: night (компрессор: тише пики, ровнее голос), voice (подъём ~2.5 кГц,
     срез низа), bass (lowshelf +7 дБ).
   - Селект в верхней панели (и в narrow/shorts — компактно). Настройка `audioPreset` в sync.
   - verify: пресеты слышны, «off» = как раньше, громкость 0–300% работает поверх.

3. **Главы на прогресс-полосе** (pip-progress.js, utils.js)
   - Границы — из нативного `.ytp-chapters-container` (переехал в окно вместе с плеером):
     ширины секций → доли длительности. Чистая функция `chapterFractionsFromWidths()` + тест.
   - Названия — из панели глав `ytd-macro-markers-list-item-renderer` на странице
     (если прогружена), иначе tooltip показывает только время.
   - Насечки на красной полоске + tooltip при наведении.
   - verify: видео с главами — насечки видны; без глав — полоска как раньше.

4. **Loop видео** (pip-controls.js)
   - Кнопка 🔁 рядом с A-B: `video.loop = !video.loop`, подсветка `ytfp-btn--active`.
   - verify: видео повторяется; повторный клик снимает.

5. **Автоскип SponsorBlock** (sponsor-block.js, constants, options, i18n)
   - Настройки: `sponsorAutoSkip` (default **false** — opt-in для Web Store),
     `sponsorCategories` (default sponsor/selfpromo/interaction; в options + intro, outro).
   - fetch использует категории из настроек; кэш-ключ = videoId + категории.
   - onTimeUpdate: автоскип → прыжок в конец сегмента; реклама YouTube не трогается
     (проверка ad-showing уже стоит в этом пути).
   - verify: сегмент проскакивает сам; выключено — старое поведение (кнопка).

6. **Мини-очередь** (pip-related.js, pip-controller.js, pip.css)
   - «+» на карточке рекомендации → очередь {videoId, title, thumb} (память страницы).
   - Секция «Очередь» сверху панели рекомендаций, удаление по клику ×.
   - По `ended` видео: берём первый из очереди, находим его anchor в DOM страницы,
     кликаем (SPA-переход — окно живёт). Anchor не найден — элемент выбрасывается,
     пробуем следующий (полная навигация закрыла бы окно).
   - pip-controller передаёт getVideo в pipRelated.build.
   - verify: 2 видео из очереди проигрываются подряд без закрытия окна.

7. **Глобальная пауза вне Chrome** (manifest.json, service-worker.js, options.html)
   - Новая команда `global-play-pause`, `"global": true`, без suggested_key
     (лимит Chrome — 4 suggested key уже заняты; клавишу юзер назначает сам).
   - SW транслирует её в существующее сообщение `play-pause`.
   - verify: назначить Ctrl+Shift+7, свернуть Chrome — пауза срабатывает.

8. **Тесты + сборка**
   - Vitest: chapterFractionsFromWidths, digitSeekTime; существующие проходят.
   - `npm test`.
