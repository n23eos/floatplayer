# FloatPlayer — Picture in Picture for YouTube

_[English version](README.md)_

Chrome-расширение (Manifest V3): выносит видео YouTube в окно **поверх всех
окон** (Document Picture-in-Picture) с собственным мини-плеером. В окне —
только само видео и элементы управления: весь остальной интерфейс YouTube
скрыт. Смотри видео и шортсы, пока работаешь в других программах.

- Chrome Web Store: материалы для публикации — [store/LISTING.md](store/LISTING.md)
- Политика конфиденциальности — [PRIVACY.md](PRIVACY.md)
- Автор — [@Raincoat_talk](https://x.com/Raincoat_talk)

## Версия 1.22.1

Время прямого эфира берётся из родных данных YouTube: завышенный медиабуфер
больше не создаёт постоянное отставание. Кнопка эфира возвращает к трансляции.
В popup добавлены версия и проверка обновлений. Подготовленное Chrome
обновление можно применить после закрытия плеера. При установке из папки
нужно заменить файлы вручную и перезагрузить расширение.

## Версия 1.22

На главной YouTube при наведении на превью появляется маленькая кнопка
FloatPlayer рядом с длительностью. Она открывает полный плеер и переводит
исходную вкладку к выбранному видео, сохраняя настройку режима окна.
Кнопка доступна с клавиатуры; на рекламе и Shorts она не появляется.

## Версия 1.20

- История последних 100 Shorts хранится только на устройстве. В настройках
  можно отключить запись и очистить историю; возврат не сбрасывает поиск.
- Через меню можно сохранить скорость и громкость для канала. Усиление

  профилей доступны в настройках. При недоступном ID канала сохранение
  сообщает об этом и не привязывает настройки к чужому ролику.
- Дата, просмотры и ID канала читаются из данных текущего видео; при
  устаревшей разметке — из страницы ролика на YouTube. Данные сверяются по ID.

## Почему лучше нативного PiP и аналогов

| | Нативный PiP Chrome | Popup-расширения | **FloatPlayer** |
|---|---|---|---|
| Поверх всех окон | ✅ | ❌ (обычное окно) | ✅ (Document PiP) |
| Перемотка, скорость, громкость | ❌ | ✅ | ✅ |
| Тот же видеопоток (без перезапуска) | ✅ | ❌ (второй плеер) | ✅ (переносится сам плеер) |
| Шортсы с автопереходом | ❌ | ❌ | ✅ |
| Шортсы по слову прямо в окне | ❌ | ❌ | ✅ |
| Чистое окно без интерфейса YouTube | ❌ | ❌ | ✅ (белый список: только видео) |

Видео не прерывается: в окно переезжает сам плеер YouTube — аккаунт, история,
качество и субтитры сохраняются. Реклама YouTube не блокируется и не
пропускается (безопасно для Web Store).

  исходной вкладки. По завершении подавляется автопереход, звук восстанавливается.
- Скрытый чат выгружается, скрытая очередь не строит обложки, реакции не
  опрашиваются без наведения в компактном режиме. Страховочная сверка таймлайна
  сокращена с 20 до 6 вызовов за минуту; события обновляют данные сразу.
- Новые строки переведены на русский и английский. В остальных локалях
  новые строки пока английские; существующие переводы сохранены.

## Возможности

### Обычные видео

- **Кнопка в плеере** (левее группы кнопок YouTube) или `Alt+P` — видео
  уезжает в мини-окно.
- **Одна нижняя панель** — полупрозрачная капсула, всплывает при наведении,
  симметрична относительно центра и не разъезжается при сужении окна:
  - ряд воспроизведения по центру:
    `[−30] [◀ предыдущее] [⏯ стоп/плей] [▶ следующее] [+30]`;
  - **громкость 0–100%** управляет обычной громкостью видео; 100–300% —
    плавное усиление через Web Audio. **Скорость**: 0.25x–3x с настраиваемым
    шагом, клик по подписи переключает пресеты 1 → 1.5 → 2;
  - **«Ещё»** открывает дополнительные инструменты ниже. Галочка рядом
    с инструментом закрепляет его на основной панели;
  - **A-B повтор** фрагмента: клик 1 — точка A, клик 2 — точка B, клик 3 —
    сброс; рядом повтор всего видео и автовоспроизведение следующего;
  - **ночной режим** двух степеней и **таймер сна** — пресеты 15–90 мин или
    своё значение (1–720 мин): по истечении видео встаёт на паузу;
  - переключатель боковой колонки (комментарии, чат, рекомендации);
  - бейдж **LIVE** на эфирах: насколько отстали от края, клик возвращает.
- **Та же панель на странице YouTube** (по желанию): громкость, скорость и
  прыжки на 30 секунд поверх обычного плеера, при наведении.
- **Красная полоска прогресса** внизу: клик и перетаскивание — перемотка,
  при наведении утолщается, засечки глав и название главы в подсказке над
  панелью. Во время рекламы над ней отдельная **белая полоска прогресса
  рекламы** (красная замирает на позиции видео).
- **Клик-зоны на видео**: левая треть — назад 10 сек, правая — вперёд 10 сек,
  центр — пауза. У края всплывает подсказка «« 10с» / «» 10с».
- **Пауза**: в центре появляется полупрозрачный значок ▶ — клик продолжает.
- **Боковая колонка**: стрелка у правого края открывает комментарии
  (бесконечная прокрутка, закреплённые и авторские отмечены), чат прямого
  эфира или колонку до 20 рекомендаций (обложка + название) — переключение
  прямо в окне, без возврата на страницу.
- **SponsorBlock**: вшитые в видео спонсорские вставки подсвечены зелёным на
  полоске прогресса и из коробки пропускаются автоматически; выключишь
  автопропуск — внутри вставки появится кнопка «Пропустить интеграцию».
  Крауд-данные sponsor.ajay.app (уходит только ID видео), функция целиком
  отключается в настройках.

### Шортсы

- **Кнопка над «лайком»** в колонке действий — шортс уезжает в вертикальное
  мини-окно (размер под 9:16).
- **Своя капсула над панелью**: `[нравится] [автопереход] [поиск]`. Дизлайка в
  разметке шортсов YouTube нет — нет его и здесь.
- **Автопереход**: ролик закончился — автоматически включается следующий
  (тумблер в капсуле и галка в настройках — одна и та же настройка).
- **Поиск по слову** (лупа): над капсулой открывается поле, вводишь слово и
  жмёшь Enter — в окне играют найденные шортсы. Вперёд/назад и автопереход
  дальше ходят по этому списку, а не по алгоритмической ленте; пока режим
  включён, лупа подсвечена, `Esc` или повторный клик его гасят. Сам поиск —
  запрос к странице `/results` самого YouTube в том же origin (новых
  разрешений и сторонних хостов не появилось), берётся первая страница выдачи
  (~30 роликов), на последнем список кончается.
- Кнопки ◀/▶ — и клавиши `↑`/`↓` — листают ленту шортсов прямо из окна.
- Узкая версия панели под вертикальное окно: без A-B и без кнопок ±30 (ролик
  короче прыжка).

### Окно

- **Перетаскивание за любое место**: зажала мышь на видео, повела — окно
  едет, отпустила — осталось. Контролы при этом кликабельны.
- **Пропорции видео**: при открытии запрашивается размер под аспект ролика;
  Chrome может применить свои ограничения или ранее выбранный размер.
  «Ещё → Размер окна» даёт три пресета и кнопку «Подогнать под видео».
  Автоподгонка включается отдельно в настройках и работает, когда Chrome
  разрешает изменение размера. Внутри окна видео всегда помещается целиком.
- **Память размера** — раздельная для горизонтальных видео и вертикальных
  шортсов. (Позицию окна задать нельзя — Document PiP API принимает только
  размер; Chrome сам частично помнит, где окно стояло.)
- **Таймер сна прячет интерфейс**: пока идёт отсчёт, все панели скрыты даже
  под курсором; движение мыши показывает их на 3 секунды.
- **Только видео**: интерфейс YouTube внутри окна скрыт «белым списком»
  (видны только видео, субтитры и спиннер) — покупки, карточки, заставки и
  любые будущие оверлеи YouTube не пролезут.
- **Два режима окна** (в настройках): «Полный (с панелью)» — описанное выше
  окно Document PiP с панелью, полоской прогресса и боковой колонкой, под
  тонкой адресной полоской Chrome; «Чистое видео (без рамки)» — нативный PiP
  вообще без адресной полоски, но и без наших панелей: только видео и
  системные кнопки.
- **Авто-PiP** (опция, Chrome 120+): ушла с вкладки — видео само вынеслось.

### Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Любое окно Chrome | `Alt+P` (⌥P на Mac) | открыть/закрыть мини-окно |
| Любое окно Chrome | `Alt+K` / `Alt+J` / `Alt+L` | пауза / −5 сек / +5 сек |
| Внутри мини-окна | `Пробел` или `K` | пауза |
| Внутри мини-окна | `←` / `→` | ±5 сек |
| Внутри мини-окна | `↑` / `↓` | громкость ±10% (в шортсах — пред./след. ролик) |
| Внутри мини-окна | `M` | mute |

Переназначение: `chrome://extensions/shortcuts`.

### Настройки (страница options)

- Стиль мини-окна: «Полный (с панелью)» / «Чистое видео (без рамки)».
- Авто-PiP при уходе со вкладки.
- SponsorBlock вкл/выкл, автопропуск вкл/выкл и категории сегментов.
- Автопереход шортсов.
- Компактный режим панели (прятать до наведения).
- Размер панели управления: ползунок 100–200% (по умолчанию 135%; на сенсорных экранах чуть крупнее).
- Панель на самой странице YouTube.
- Шаг ползунка скорости (0.1x / 0.25x / 0.5x).
- Потолок громкости (100/200/300%).
- Интерфейс: английский по умолчанию, русский для русскоязычных браузеров.

### Прочее

- Форма обратной связи открывается при удалении расширения (Google Form).
- Минимальные разрешения: `storage` + хосты youtube.com и
  sponsor.ajay.app. Без сборщика, без remote code, без аналитики.

## Установка (разработка)

1. `chrome://extensions` → «Режим разработчика».
2. «Загрузить распакованное расширение» → папка **`extension/`** (именно она,
   не корень репозитория).
3. Открыть видео на YouTube; после обновления расширения — F5 на вкладках YouTube.

Сборка для Web Store: `npm run build` → `dist/floatplayer-<версия>.zip`.

## Ограничения (честно)

- Chrome 116+ (на старых — фолбэк на нативный PiP).
- Верхнюю полоску Chrome с адресом сайта убрать нельзя — анти-фишинговое
  требование браузера для всех Document PiP окон (автоскрывается без
  наведения). Полностью без полоски — режим «чистое видео».
- Прозрачность окна и «клик сквозь» невозможны в Chrome API.
- Одно PiP-окно на браузер.
- Позиция окна программно не задаётся (только размер).
- Во время рекламы YouTube перемотка недоступна — мотать нечего, основное
  видео в этот момент не загружено.

## Проверка разработки

`npm run check` проверяет версии, синтаксис JS и ресурсы манифеста/HTML.
`npm run build` сначала запускает эту проверку и все тесты, затем создаёт ZIP.

`npm run preview` запускает локальный стенд по адресу
`http://127.0.0.1:8765/watch?v=AAAAAAAAAAA` (нужен ffmpeg для создания
тестового видео). Это настоящий Document PiP с модулями расширения,
но API YouTube и chrome.storage заменены. Стенд не подтверждает совместимость
с живым YouTube и не входит в ZIP. Состояние работы — в [STATUS.md](STATUS.md).

## Разработка через OpenSpec

Будущие доработки ведутся через OpenSpec: описание → спецификации → дизайн →
задачи → реализация → проверки → архив. В Codex начните с
`$openspec-propose <описание доработки>`.
Установка: `npm ci`; проверка спецификаций: `npm run spec:check`.
Подробный процесс и команды: [docs/openspec.md](docs/openspec.md).

### Главы и режимы PiP
В режиме «С управлением» доступны текущая глава и список переходов, когда
YouTube предоставляет данные глав. Компактный режим скрывает интерфейс при
уходе курсора. Режим «Только видео» использует Native PiP Chrome и не содержит
собственных элементов глав. Выбор режима доступен на странице и в popup.
