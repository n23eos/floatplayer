## Решения после перепроверки

- Остаются vanilla JS, Manifest V3 и Vitest; сборщик/фреймворк не добавляем.
- Очередь хранится локально для вкладки и переживает reload; удаление ролика
  из очереди только после подтверждённого перехода, ошибка видна пользователю.
- Таймер живёт в content-контексте вкладки и переживает закрытие PiP;
  при завершении блокирует автопереходы, затем восстанавливает громкость.
- Режим document/native применяется при следующем открытии: переключение
  открытого окна требует пользовательского жеста и не должно терять видео.
- Размер меняется по кнопке; автоматическая подгонка остаётся опциональной.
- Субтитры используют существующий плеер YouTube; недоступный язык/CC
  показывается как недоступный, ошибки не маскируются.
- Новые строки: полноценные EN/RU; остальные локали получают английский
  fallback без фиктивных переводов.
